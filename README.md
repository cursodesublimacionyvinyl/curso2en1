# Portal del estudiante — GitHub Pages

Contenedor publico ligero. El formulario real de registro y login se ejecuta en un iframe del web app de Google Apps Script. **No hay usuarios ni contraseñas en estos archivos.**

- Ajusta **solo** `config.js` con la URL `/exec` del despliegue real de Apps Script.
- Publica esta carpeta en GitHub Pages.
- No publiques aquí `Code.gs`, `.env`, tokens de Telegram, datos de estudiantes ni videos privados.
- No copies todavía las herramientas DTF/Mockups como HTML publicos, porque alguien podría ejecutar esas herramientas sin licencia a través de su URL.

Ver `../GUIA_INSTALACION.md`.
